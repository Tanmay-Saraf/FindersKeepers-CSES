# FindersKeepers-CSES

## Terrain materials

The main map's Terrain3D material library is configured in `Materials/main_map_terrain_assets.tres`. Its texture slots are Rock Ground (ID 0), Grass Ground (ID 1), and Sand 03 (ID 2), using texture maps under `Textures/terrain/`.

The island prop uses the separate `Materials/island_sand_material.tres` material, assigned to the terrain surface in `Maps/island_part.tscn`.
